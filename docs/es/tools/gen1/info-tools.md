# Herramientas de Información Gen1

## 1. Tools
- `nature_checker.lua`
- `tidbot.lua`
- `shiny_checker.lua` (stub)

## 2. `nature_checker.lua`
- Muestra las Natures (basadas en Exp % 25) de tu equipo. También marca los shiny en la pantalla.
- No requiere configuración.

## 3. `tidbot.lua`
- Busca un Trainer ID (TID) específico automáticamente reiniciando el juego.
- **Configuración:** Editar `local desired_tid = <numero>` en el archivo.

## 4. Limitaciones
- `shiny_checker.lua` no tiene funcionalidad implementada actualmente.
