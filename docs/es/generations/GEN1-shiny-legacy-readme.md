# CAZA SHINY

Solo funciona con vba rr 23.6. Las nuevas versiones y otros emuladores están en progreso.

Recomiendo no acelerar el emulador o algunos scripts no funcionarán correctamente.

Dentro de cada carpeta hay un pequeño video mostrando cómo se vería la ejecución.

## BOTS DE PESCA ##

Selecciona tu caña, coloca el cursor sobre "USAR" y ejecuta el script.

![](https://i.imgur.com/0y7aQeW.png)

Dentro de cada script de pesca hay una opción llamada OP. Si inicializas esta variable local a 7, podrás ver los DVs de cada Pokémon obtenido tras Soft Reset.

- **autospecie_fishingbot.lua**
  Este script seleccionará y buscará shiny automáticamente del primer Pokémon que encuentre.

- **fishbot.lua**
  Edita el script con el número de índice deseado.
  Los índices se encuentran aquí: http://bulbapedia.bulbagarden.net/wiki/List_of_Pok%C3%A9mon_by_index_number_(Generation_I)
