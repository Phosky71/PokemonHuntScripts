# Security Policy

## Supported Versions

We track security updates for the latest stable version of PokemonHuntScripts.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability within PokemonHuntScripts, please report it responsibly. **Do not disclose security vulnerabilities publicly** until they have been addressed by the maintainers.

To report a vulnerability:
1. Open a confidential security advisory or contact the maintainers via GitHub.
2. Provide a detailed description of the vulnerability, including:
   - Steps to reproduce.
   - Affected scripts or components.
   - Potential impact.
3. Allow up to 48 hours for an initial response.

## Security Best Practices
- Always download ROMs from trusted personal backups.
- Do not run untrusted Lua scripts downloaded from unverified sources in your emulator.
- Keep your emulator (VBA-M rr 23.6, mGBA, BizHawk, DeSmuME, Dolphin) up to date.
- Be cautious with memory-manipulation scripts as they interact directly with emulator state.

Thank you for helping keep PokemonHuntScripts secure!
