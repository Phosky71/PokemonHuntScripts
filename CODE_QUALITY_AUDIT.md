## 2. Findings Log

### H-MED-001: Unintended Global Variables in `gsc_unown.lua`
- **Severity:** MEDIUM
- **Tool / File:** `tools/gen2/gsclua/Bots/Wild/gsc_unown.lua`
- **Location:** Lines 46–53 (`getUnownForm` function)
- **Description:** `getUnownForm` declared `spcbits`, `spebits`, `defbits`, `atkbits`, and `formid` without the `local` keyword, accidentally exposing them to the global namespace.
- **Evidence:** Code inspection of `wwwwwwzx/gsclua` original source.
- **Applied Fix:** Added `local` scoping keywords to all 5 variables inside the function in commit `0fff54f`.
- **Validation:** Syntax check and logic verification confirmed scope is now confined to the function.
